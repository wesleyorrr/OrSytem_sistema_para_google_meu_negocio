# 🏪 OR System — Sistema para Google Meu Negócio

> **Aplicação web para apresentação e gestão de negócios no Google Meu Negócio** — parte do ecossistema **OR System**.

Página estática desenvolvida para ajudar negócios locais a se apresentarem de forma profissional e a entenderem/otimizarem sua presença no **Google Meu Negócio**, com foco em **usabilidade, clareza visual e conversão**.

---

## 📖 Sobre o projeto

O **OR System — Sistema para Google Meu Negócio** é uma aplicação web pensada para **negócios locais** que desejam fortalecer sua presença digital e facilitar o contato com clientes por meio do Google. A página apresenta o negócio de forma organizada, comunica seus serviços e direciona o visitante para ações de contato ou localização.

Faz parte do ecossistema **OR System**, marca voltada a soluções digitais com foco em **simplicidade, performance e funcionamento offline-first**.

### 🎯 Problema que resolve

Ajudar **pequenos negócios locais** a terem uma presença digital organizada e alinhada ao Google Meu Negócio, sem depender de sistemas complexos ou agências caras — oferecendo uma vitrine simples, funcional e pronta para conversão.

### 👥 Público-alvo

- Pequenos comerciantes e negócios locais
- Prestadores de serviço que querem aparecer melhor no Google
- Empreendedores iniciando a presença digital
- Uso interno da OR System

---

## ✨ Funcionalidades

- Apresentação profissional do negócio 🏪

## 🧠 Decisões técnicas & aprendizados

- **Vanilla JS em vez de frameworks**: escolha consciente para manter o bundle leve, o carregamento rápido e o código acessível a qualquer dev que for dar manutenção.
- **Arquitetura estática**: sem backend, o que reduz custo de hospedagem e simplifica o deploy via GitHub Pages.
- **Separação de responsabilidades**: `index.html` (estrutura), `style.css` (apresentação) e `script.js` (comportamento) organizados de forma clara.
- **Foco em conversão local**: estrutura pensada para guiar o visitante até o contato ou localização do negócio.
- **Offline-first**: a aplicação continua funcional sem conexão após o primeiro carregamento.
